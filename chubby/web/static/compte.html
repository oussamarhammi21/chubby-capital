Journal du vrai compte

    Brancher Interactive Brokers

    1. Ouvre un compte chez Interactive Brokers Canada, puis active le compte papier dans ton espace client (Paramètres, Compte papier).
    2. Installe IB Gateway sur ce PC et connecte-toi avec l'identifiant du compte papier.
    3. Dans IB Gateway : Configure, Settings, API, Settings. Coche « Enable ActiveX and Socket Clients », décoche « Read-Only API ». Le port papier est 4002.
    4. Installe le branchement : pip install -e ".[ibkr]", puis teste : python -m chubby.cli vrai connexion.
    5. Choisis ton guide et tes garde-fous ici, puis Démarrer. Laisse python -m chubby.cli web tourner pendant la bourse.

    Pour l'argent réel plus tard : connecte IB Gateway avec ton vrai identifiant, mets IBKR_PORT=4001 dans le fichier .env, et choisis « Réel » ci-dessus.
